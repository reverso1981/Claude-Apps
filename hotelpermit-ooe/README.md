# HotelPermit OÖ — Behörden-Navigator

Single-File-Web-App (Business Upper Austria) zur Ermittlung der zuständigen
Behörden und der erforderlichen Unterlagen bei Hotel- und Beherbergungs-
projekten in Oberösterreich.

## Nutzung

`index.html` im Browser öffnen — keine Installation, kein Build, keine
Server-Komponente nötig. Alle Logik, Styles und Daten sind in der Datei
enthalten; extern geladen wird lediglich die Schriftart (Google Fonts).
